# Rencana implementasi UI messaging

## Batas global

Backend Python dan kontrak WebSocket tidak diubah. Tidak ada dependency baru. UI Bahasa Indonesia; kode Bahasa Inggris. Dials ENERGY 2 / RHYTHM 2 / MOTION 1. Roster nyata menggantikan usulan daftar conversation; tidak ada room/channel palsu.

## Urutan dan pembagian

1. Adapter timeline frontend, `web/lib/bridge.tsx` dan `web/lib/messages.ts`. Ganti dua buffer lines/messages dengan timeline gabungan maksimal 1000 entri, sequence monotonik. Bubble memakai envelope; terima hanya tiga jenis output lokal bridge sebagai line fallback. Filter envelope heartbeat/handshake yang tidak punya konten tampilan. Identitas own disimpan saat penerimaan agar /nick tidak mengubah sisi pesan lama. API komponen: timeline: TimelineEntry[], setiap entri memiliki sequence; kind message membawa message: Envelope dan own: boolean, kind line membawa text: string. messages.ts mengekspor formatMessageTime dan systemMessageText untuk presentasi. Pertahankan action bridge yang ada dan trace buffer.
2. Shell dan chat, `app/globals.css`, `app/layout.tsx`, `app/page.tsx`, `components/SiteNav.tsx`, `ThemeToggle.tsx`, `ConnectBar.tsx`, `MessageLog.tsx`. Roster kiri, transcript dominan, panduan kanan pada layar lebar. Komposer di bawah transcript. Warna dasar hangat, bubble berjenjang dan typography sans. Keempat warna layer terpisah dipertahankan. Perbarui focus, empty/loading/error, mobile layout, target kontrol 44 px, long-word wrapping.
3. Visualizer, `app/visualizer/page.tsx`, `components/TraceLadder.tsx`. Gunakan token tema yang sama dan class panel/button bersama tanpa mengubah data, grouping, atau trace semantics. Details byte dan tombol Kosongkan tetap berfungsi.
4. Setelah semua edit, jalankan `npm run typecheck` dan `npm run build` sekali sebagai gerbang integrasi. Jalankan aplikasi dan browser 3 client dengan server/bridge nyata. Uji pesan biasa/pribadi, output lokal, batas timeline, /nick, nickname duplikat, input salah, pesan besar, user hilang, reconnect/disconnect, kedua tema dan ukuran viewport. Uji visualizer dengan trace nyata. Catat bukti screenshot dan rasio kontras, tanpa menambah test runner.

## Kontrak pekerjaan paralel

Main memiliki stylesheet, shell, chat components dan integrasi. TimelineAdapter hanya mengubah lib/messages.ts dan lib/bridge.tsx. VisualizerPolish hanya mengubah app/visualizer/page.tsx dan components/TraceLadder.tsx. Tidak ada task yang menjalankan formatter, lint, build atau tests saat task lain masih mengedit. Main melakukan seluruh verifikasi setelah integrasi. Shared class: panel, button-secondary, section-label; Tailwind token paper/surface/ink/muted/line/control-line/accent/accent-ink/l7/l6/l5/l4/danger tetap tersedia.
